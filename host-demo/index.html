Страница магазина (отдельный origin)

Это учебный host на порту 5180. Виджет грузится script’ом с frontend (5173) и открывается в iframe — без правок «сайта».

Сессия чата хранится в first-party storage iframe. Закрытие лаунчера не уничтожает iframe, поэтому история переживает reopen. Токен и cartId через postMessage/URL не передаются.
