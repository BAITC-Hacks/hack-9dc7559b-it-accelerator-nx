# Проверка подключённого интерфейса

Запуск: `docker compose --profile full up -d --build --wait`.
Сайт: http://localhost:5173. Встраиваемая версия: http://localhost:5180.

Интерфейс использует сгенерированный OpenAPI-клиент; подключены все 47 операций SDK.
В production-сборке используются реальные API. Учебные драйверы доступны отдельно через `npm run dev:mock`.

| Раздел | Что проверить |
| --- | --- |
| `/` | Создать диалог, отправить сообщение, получить потоковый ответ, остановить/восстановить, обновить страницу. Справа — чтение/изменение контекста и последний подбор. Под ответом — источники и расход модели. |
| `/catalog` | Артикул `000001`, текстовый поиск, фильтры, режимы GET/POST/обзор, сравнение, карточка, цены по складам, PDF-сертификат, аналоги и комплектации. |
| `/cart` | В каталоге выбрать товар/склад/количество → «Посмотреть точное предложение» → «Подтвердить этот состав». Проверить состав корзины, отклонение предложения и статус операции при неопределённом результате. |
| `/attachments` | Выбрать диалог и загрузить `data/attachments/office/specification.xlsx`. Дождаться строк, выбрать товары/склады, сохранить каждую строку или исключить. Связать проверку с чатом либо сформировать предложение. Доступны оригинал, повторная обработка, удаление и восстановление файла по ID. |
| `/knowledge` | Вопрос «Какие условия доставки?» → источники → полный текст конкретной версии и скачивание. |
| `/admin` | JSON-импорт каталога и статус задания, добавление/индексация/отзыв документов, изменение sample-цен/остатков с проверкой версии, расход модели по run ID. |
| `/session` | Текущий пользователь и корзина, продление, выход, вход с ранее выданным токеном. |
| `/status` | Проверка связи браузер → backend. |

Для гостевого входа в локальной `.env` нужен `VISITOR_SESSION_ENABLED=true`; для распознавания — `ATTACHMENT_OCR_ENABLED=true` и при необходимости `ATTACHMENT_VISION_ENABLED=true` с действующим OpenAI API key.
Админские операции требуют `ADMIN_PRINCIPAL_IDS`: возьмите ID из `/session`, добавьте в локальную `.env` и выполните `docker compose up -d backend`. Роль проверяется сервером. Новая гостевая сессия автоматически административных прав не получает.

Проверено при интеграции: backend build и 128 тестов; frontend build/lint и 52 теста; в браузере — реальный ответ чата, поиск по источникам, каталог → предложение → подтверждение корзины, загрузка Excel → распознанные строки. Для синтетических данных операции корзины выполняются в sample-адаптере.
