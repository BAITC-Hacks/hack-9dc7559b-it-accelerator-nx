# Архитектура объединена с продуктовым ТЗ

Актуальный единый документ: [ekt-assistant-spec.md](ekt-assistant-spec.md).

Он объединяет исходное ТЗ ekt.kz, архитектуру чата/RAG и нагрузочные требования с учётом нового каталога V2. Корзина с Confirm Gate, bounded tool calling, Excel/Word/PDF/JPEG и mobile embed теперь входят в обязательную поставку.

Подробные карточки и распределение между тремя разработчиками: [tasks/README.md](../tasks/README.md). Предыдущая версия архитектуры доступна в истории Git; использовать её ограниченный scope для реализации больше не следует.
